# ArthSathi

# 💰 ArthSathi – Personal Expense Tracker

ArthSathi is a modern personal finance management web application that helps users track their income and expenses, monitor spending habits, and visualize financial data through interactive charts. The project is built using HTML, CSS, and JavaScript with a responsive and user-friendly interface.

---

## 🚀 Features

* 📊 Interactive Analytics Dashboard
* ➕ Add, Edit, and Delete Transactions
* 💰 Track Income and Expenses
* 🏦 Automatic Balance and Savings Calculation
* 📈 Expense by Category Chart
* 📉 Monthly Expense Trend
* 🥧 Income vs Expense Visualization
* 📌 Spending Pattern Analysis
* 🔍 Search Transactions
* 🎯 Filter by Category
* ↕️ Sort by Date and Amount
* 🌙 Light/Dark Mode
* 📱 Responsive Design
* 💾 Data stored using Local Storage
* 🔔 Toast Notifications
* ✨ Modern UI with hover effects

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Chart.js
* Font Awesome

---

## 🌙 Dark Mode

ArthSathi supports both Light and Dark themes.

* Theme preference is saved using Local Storage.
* Charts and UI adapt to the selected theme.

---

## 💾 Data Storage

This project uses the browser's **Local Storage**, so no database is required.

Transactions remain available even after refreshing the page.

---

## 📱 Responsive Design

The application is responsive and works on:

* Desktop
* Tablet
* Mobile Devices

## ▶️ How to Run

1. Clone the repository.

```bash
git clone https://github.com/your-username/ArthSathi.git
```

2. Open the project folder.

3. Open `landingpage.html` in your browser.

No installation or backend setup is required.
